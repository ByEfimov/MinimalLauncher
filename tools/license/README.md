# Активация Minimal Drive (защита от копирования)

Скопированный APK без активации показывает экран блокировки с **кодом магнитолы**.
Код активации — это подпись этого кода **приватным ключом**, который есть только у вас.
Магнитола проверяет подпись встроенным **публичным** ключом офлайн: подделать нельзя,
и код от одной магнитолы не подходит к другой. После активации интернет не нужен.

Ключи уже сгенерированы. **Приватный ключ никогда не попадает в репозиторий.**

## Вариант A — активация с телефона (Cloudflare Worker, бесплатно)

Разово на Mac:

```bash
cd ~/Проекты/MinimalLauncher/tools/license
npm i -g wrangler && wrangler login          # вход в Cloudflare (откроется браузер)
wrangler kv namespace create DEVICES         # скопируйте id → впишите в wrangler.toml
wrangler secret put PRIVATE_KEY_PKCS8         # вставьте содержимое ~/Проекты/MinimalLauncher-secret/private_pkcs8.pem
wrangler secret put ADMIN_PASS                # придумайте пароль
wrangler deploy                               # выдаст адрес https://minimal-drive-license.<вы>.workers.dev
```

Впишите этот адрес в `gradle.properties` → `activationUrl=https://…workers.dev`, и следующая
сборка (пуш в main) будет знать про сервис.

Активация новой магнитолы **с телефона**:
1. Откройте адрес Worker'а в браузере телефона, введите пароль (сохранится).
2. Впишите код с экрана магнитолы (например `8B46-EA8A-08F4`) → «Активировать».
3. Магнитола активируется сама при следующем запуске (нужен интернет один раз).
   Если она офлайн — скопируйте показанный «код активации» и вставьте его на магнитоле
   кнопкой «Вставить код активации».

Отозвать доступ: та же страница → «Отозвать» (магнитола не потеряет активацию мгновенно,
но перестанет активироваться заново и не получит обновлений, если отключить ей выдачу).

## Вариант B — офлайн, с Mac, без сервера

```bash
tools/license/sign.sh 8B46-EA8A-08F4
```
Выведет код активации — продиктуйте/пришлите его, на магнитоле «Вставить код активации».

## Файлы ключей (на Mac, вне репозитория)

Положите в `~/Проекты/MinimalLauncher-secret/`:
- `private.pem` — для sign.sh
- `private_pkcs8.pem` — для Worker'а (secret PRIVATE_KEY_PKCS8)

Публичный ключ уже вшит в приложение (`License.kt`). Если потеряете приватный ключ —
сгенерируйте новую пару и замените публичный ключ в приложении (старые активации перестанут подходить).
