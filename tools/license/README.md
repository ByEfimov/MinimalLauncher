# Активация Minimal Drive (защита от копирования)

Скопированный APK без активации показывает экран блокировки с **6-значным кодом магнитолы**.
Код активации — тоже 6 цифр, привязан к коду магнитолы, и **проверяется офлайн** на самой магнитоле.
Интернет магнитоле не нужен вообще.

## Как выдать код — с телефона, без интернета (рекомендуется, работает в России)

Файл `activator.html` — автономный генератор. В нём ваш секретный ключ, поэтому **храните его при себе
и не выкладывайте в интернет**.

1. Перешлите `activator.html` себе на телефон (AirDrop, почта, мессенджер) и откройте — он работает офлайн.
2. Введите 6-значный код с экрана магнитолы → сразу увидите **код активации**.
3. Продиктуйте/пришлите его. На магнитоле введите код в поле «Код активации». Готово.

## Как выдать код — с Mac, без интернета

```bash
tools/license/sign.sh 373039
```
Выведет 6-значный код активации.

Секрет для обоих способов лежит вне репозитория: `~/Проекты/MinimalLauncher-secret/hmac_secret.hex`.

## Онлайн-сервис (Cloudflare Worker) — НЕ рекомендуется для России

Адрес `*.workers.dev` заблокирован в России, поэтому и телефон, и магнитола не могут до него достучаться.
Файлы `worker.js` / `wrangler.toml` оставлены на случай, если понадобится сервис вне России. Для России
пользуйтесь `activator.html` или `sign.sh` — они не требуют интернета. В сборке `activationUrl` оставлен пустым,
поэтому магнитола не ходит в сеть за активацией и активируется только введённым кодом.

## Файлы ключей (на Mac, вне репозитория)

`~/Проекты/MinimalLauncher-secret/hmac_secret.hex` — секрет. Тот же секрет вшит в приложение (`License.kt`,
обфусцирован) и в `activator.html`.

**Компромис:** 6-значный код требует общего секрета, поэтому он лежит и в приложении. Это останавливает
обычное копирование, но при разборе APK секрет можно извлечь.
