# Прокси на Yandex Cloud (погода + ограничения скорости в белом списке РФ)

Магнитола обращается только к адресу `*.yandexcloud.net` (белый список РФ, работает при ограничениях
интернета), а функция уже сама ходит за погодой (Open-Meteo) и ограничениями скорости (Overpass).

## Настройка (один раз, ~10–15 минут)

1. Зайдите в консоль **console.yandex.cloud** (нужен аккаунт Яндекса; для функций хватает бесплатного
   уровня — миллион вызовов в месяц бесплатно). Создайте «Платёжный аккаунт» (карта нужна для активации,
   но в рамках free tier списаний не будет).
2. Создайте каталог (folder), если его нет.
3. **Cloud Functions → Создать функцию** → имя, например `minimal-drive-proxy`.
4. Создайте версию:
   - Среда выполнения: **Node.js 18**.
   - Способ: «Редактор кода». Создайте файл `index.js`, вставьте содержимое `tools/proxy/index.js`.
   - Точка входа: `index.handler`.
   - Таймаут: 10 секунд, память: 128 МБ.
   - Сохраните.
5. Сделайте функцию публичной: на странице функции включите **«Публичная функция»**.
6. Скопируйте адрес вызова — он вида `https://functions.yandexcloud.net/<id функции>`.
7. На магнитоле: **Настройки → Карта → «Прокси (Yandex Cloud)»** → вставьте этот адрес → «Сохранить».

Готово. Погода и ограничения скорости теперь идут через ваш адрес на `yandexcloud.net`.

## Проверка

Откройте в браузере (подставьте свой адрес):
`https://functions.yandexcloud.net/<id>?action=weather&lat=55.75&lon=37.62`
— должен вернуться JSON с погодой.

## Примечания

- Если `*.yandexcloud.net` у вашего оператора всё же режется при блокировках — сообщите, подберём
  другой белосписочный хостинг (например, размещение статики/функции на домене Яндекса иначе).
- Без прокси приложение использует запасные источники (wttr.in, met.no, Open-Meteo для погоды;
  зеркала Overpass для ограничений) — они работают, пока нет жёстких ограничений.
