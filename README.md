# Minimal Drive

Минималистичный лаунчер для магнитол TEYES (проверялся на CC3, Android 10, 1280×720).
Музыка (Яндекс Музыка / Bluetooth), карта с маршрутами, скорость и ограничения, режим «настоящего лаунчера».

## Установка (для любого пользователя)
1. Скачайте последний `MinimalDrive-x.y.z.apk` со страницы **Releases** этого репозитория.
2. Скопируйте на флешку → вставьте в магнитолу → откройте APK в файловом менеджере → «Установить».
3. Нажмите «Домой» → выберите **Minimal Drive** → «Всегда».
4. Пройдите экран **«Настройка магнитолы»** (открывается сам): имя, лаунчер по умолчанию, доступы.
5. Дальше приложение обновляется само: Настройки → Обновления (проверка раз в сутки).

### Яндекс Карты (по желанию)
Без ключа работает OpenStreetMap (поиск, маршруты, всё бесплатно).
Для карты Яндекса с пробками: ключ MapKit на https://developer.tech.yandex.ru → «MapKit Mobile SDK»,
затем Настройки → Карта → вставить ключ → «Сохранить и перезапустить». У каждого пользователя свой ключ.

## Возможности
- **Музыка:** две вкладки — Яндекс Музыка и Bluetooth (любой плеер, кроме Яндекса). Вкладка сама переключается на то, что начало играть; другой плеер ставится на паузу. Свайп по карточке — следующий/предыдущий трек.
- **Карта:** всегда на главном экране, тёмная, следует за машиной. ⌂ — маршрут домой, 🔍 — поиск адреса. Слева сверху — следующий манёвр, снизу — время, расстояние и прибытие. ⤢ — открыть Яндекс Навигатор с тем же пунктом назначения.
- **Скорость и ограничения** по GPS и OpenStreetMap (правила РФ для дорог без знака), звук при превышении и перед камерами.
- **Лаунчер:** не выпускает в штатный лаунчер TEYES, запускается после включения зажигания, продолжает музыку.
- **Диагностика:** Настройки → Диагностика → «Проверить сервисы» — какие интернет-сервисы доступны с магнитолы.

## Разработка
Android Studio → Open → эта папка. Сборка: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`.

Ключ подписи `keystore/minimal-drive.jks` лежит только у вас локально (в git его нет). Без него обновления не встанут поверх установленной версии — **сохраните копию**.

## Релизы и автообновление
Один раз:
1. Репозиторий должен быть **публичным** (иначе магнитолы не увидят Releases).
2. GitHub → Settings → Secrets and variables → Actions → **New repository secret**
   `SIGNING_KEYSTORE_B64` = результат команды `base64 -i keystore/minimal-drive.jks | pbcopy` (скопируется в буфер).

Каждый релиз:
```
./release.sh 1.2.0
```
GitHub Actions соберёт подписанный APK и опубликует релиз `v1.2.0`; магнитолы предложат обновиться.
